# HopeHands Foundation Website

A complete responsive NGO website created for the InAmigos Foundation Task 3 – AI Website Generation demonstration.

## Included
- Responsive homepage
- About section
- Causes and programs
- Impact statistics
- Volunteer / Donate / Partner section
- Success stories
- Contact form
- Mobile navigation
- Modern NGO design

## Run
Open `index.html` in a browser.

## Publish
This static website can be published free using GitHub Pages, Netlify, or Vercel.
